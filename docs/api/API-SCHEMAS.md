# StudyPath SA — Reusable Schemas

**Contract version:** 1.0.0-draft. Names and casing are normative for this contract; implementation is not verified.

## 1. Primitive and enum definitions

| Type | Definition |
|---|---|
| `CatalogueId` | String matching `^[A-Z0-9][A-Z0-9._-]{0,99}$`; stable and case-sensitive |
| `ContractVersion` | Semver string; this draft is `1.0.0-draft` |
| `CatalogueVersion` | Non-empty opaque version string for a published catalogue snapshot |
| `ISODate` | `YYYY-MM-DD`, Gregorian calendar date |
| `DateTimeUTC` | RFC 3339 timestamp ending in `Z` |
| `EligibilityStatus` | `ELIGIBLE` | `NOT_ELIGIBLE` | `UNKNOWN` |
| `PublicationStatus` | `PUBLISHED` | `EXPIRED` |
| `RequirementOperator` | `GTE` | `GT` | `LTE` | `LT` | `EQ` | `IN` | `ALL_OF` | `ANY_OF` | `CONDITIONAL` |
| `PathwayRelationshipType` | `PROGRESSION` | `ALTERNATIVE` | `RELATED_FIELD` | `ARTICULATION` |
| `ApplicationTargetType` | `PROGRAMME` | `FUNDING_OPPORTUNITY` |
| `ApplicationStatus` | `DRAFT` | `READY_TO_SUBMIT` | `SUBMITTED` | `AWAITING_DOCUMENTS` | `UNDER_REVIEW` | `ACCEPTED` | `REJECTED` | `WITHDRAWN` |
| `DocumentChecklistStatus` | `NOT_STARTED` | `IN_PROGRESS` | `READY` | `NOT_REQUIRED` |

## 2. API error schema

```json
{
  "error": {
    "code": "CATALOGUE_UNAVAILABLE",
    "message": "The catalogue is temporarily unavailable. Try again later.",
    "requestId": "opaque-correlation-id"
  }
}
```

All three fields are required on HTTP error responses. `requestId` is an opaque, non-secret correlation ID generated by the trusted API boundary. Never include learner values, tokens, stack traces, SQL text or configuration.

## 3. Source provenance

```json
{
  "sourceId": "UJ-2027-PROSPECTUS",
  "sourceName": "Official source title",
  "publisher": "Official publisher",
  "sourceUrl": "https://example.org/official-source",
  "sourceSection": "Section/page reference or null",
  "verifiedAt": "2026-10-16T12:00:00Z",
  "applicableCycle": "2027",
  "evidenceNote": "Faithful concise transcription of the applicable official rule"
}
```

Required fields: `sourceId`, `sourceName`, `publisher`, `sourceUrl`, `verifiedAt`, `applicableCycle`. `sourceSection` and `evidenceNote` may be null only when the source genuinely provides no section/evidence text; a rule used for definitive eligibility still requires traceable rule evidence. URLs must be HTTPS. Dates and cycles must not be inferred.

## 4. Requirement rule schema

```json
{
  "ruleId": "RULE-MATH-01",
  "requirementType": "SUBJECT_MARK",
  "operator": "GTE",
  "subjectId": "MATHEMATICS",
  "threshold": 60,
  "acceptedValues": null,
  "conditionRuleId": null,
  "mandatory": true,
  "description": "Mathematics at least 60%",
  "sourceIds": ["UJ-2027-PROSPECTUS"],
  "verificationState": "VERIFIED"
}
```

Fields:
- `ruleId`: stable `CatalogueId`.
- `requirementType`: `SUBJECT_MARK`, `APS`, `LANGUAGE`, `QUALIFICATION`, `RESIDENCY`, `FINANCIAL`, `DOCUMENT`, `OTHER`, or a future versioned extension.
- `operator`: one of `RequirementOperator`.
- `subjectId`: canonical subject ID or null when not subject-specific.
- `threshold`: finite number or null; percentage thresholds must be whole numbers 0–100.
- `acceptedValues`: array of strings or numbers, or null.
- `conditionRuleId`: rule ID or null.
- `mandatory`: boolean.
- `description`: non-empty learner-facing explanation.
- `sourceIds`: one or more IDs resolving to provenance records for any rule used in eligibility.
- `verificationState`: `VERIFIED` | `UNKNOWN`.
Unknown rule semantics, APS formula, subject inclusion/exclusion or unsupported conditions must produce `UNKNOWN` when they could change the result. No universal APS formula is implied.

## 5. Programme record

```json
{
  "id": "UJ-2027-BSC-IT",
  "institution": {
    "id": "UJ",
    "name": "Institution name",
    "institutionType": "UNIVERSITY",
    "province": "GAUTENG",
    "websiteUrl": "https://example.org"
  },
  "title": "Exact official programme title",
  "qualificationType": "DEGREE",
  "nqfLevel": null,
  "durationYears": 3,
  "studyModes": ["ON_CAMPUS"],
  "locationText": "Official campus/location text",
  "applicableCycle": "2027",
  "requirements": [],
  "relationships": [],
  "sources": [],
  "verifiedAt": "2026-10-16T12:00:00Z",
  "catalogueVersion": "2026-10-16.1",
  "publicationStatus": "PUBLISHED",
  "curatorApproved": true,
  "limitations": []
}
```

Required: `id`, `institution`, `title`, `qualificationType`, `studyModes`, `applicableCycle`, `requirements`, `relationships`, `sources`, `verifiedAt`, `catalogueVersion`, `publicationStatus`, `curatorApproved`, `limitations`. `nqfLevel`, `durationYears`, `locationText` and `institution.websiteUrl` may be null if not confirmed. `durationYears` must be greater than zero when present. `curatorApproved` must be true for a record returned by API-001.

Enums:
- `institutionType`: `UNIVERSITY` | `TVET_COLLEGE` | `OTHER`.
- `qualificationType`: `DEGREE` | `DIPLOMA` | `HIGHER_CERTIFICATE` | `TVET` | `OTHER`; use only when supported by the official source.
- `studyModes`: `ON_CAMPUS` | `ONLINE` | `DISTANCE` | `HYBRID` | `UNKNOWN`. Do not infer mode.
- `province`: South African province enum: `EASTERN_CAPE`, `FREE_STATE`, `GAUTENG`, `KWAZULU_NATAL`, `LIMPOPO`, `MPUMALANGA`, `NORTHERN_CAPE`, `NORTH_WEST`, `WESTERN_CAPE`, `UNKNOWN`.

## 6. Pathway relationship record

```json
{
  "id": "REL-UJ-PROG-A-PROG-B",
  "fromProgrammeId": "UJ-2027-BSC-IT",
  "toProgrammeId": "UJ-2027-BSC-CSI",
  "type": "RELATED_FIELD",
  "rationale": "Curator-approved learner-facing rationale",
  "evidenceStatus": "VERIFIED",
  "sourceIds": ["UJ-2027-PROSPECTUS"],
  "applicableCycle": "2027",
  "verifiedAt": "2026-10-16T12:00:00Z",
  "reviewBy": "2026-11-15",
  "curatorApproved": true,
  "caveat": "The target programme's admission criteria apply separately."
}
```

Only `VERIFIED`, curator-approved relationships with complete source/cycle/rationale evidence may be returned in `relationships`. `evidenceStatus` domain values are `PROPOSED`, `VERIFIED`, `REJECTED`, `EXPIRED`, but public API output must contain `VERIFIED` only. Similar names or general qualification levels do not establish articulation. An empty relationship list is valid.

## 8. Catalogue response schemas

Programme list:
```json
{
  "contractVersion": "1.0.0-draft",
  "catalogueVersion": "2026-10-16.1",
  "generatedAt": "2026-10-16T12:00:00Z",
  "items": []
}
```

Funding list has the same envelope and `FundingOpportunity` items. `items` is required, may be empty, and is ordered by `id` ascending. `generatedAt` means response generation time, not source verification time.

## 9. Local interface schemas

### MatchInput
```json
{
  "stage": "GRADE_12",
  "subjects": [{"subjectId": "MATHEMATICS", "mark": 75}],
  "interests": ["SOFTWARE_DEVELOPMENT"],
  "province": "GAUTENG",
  "studyModes": ["ON_CAMPUS"]
}
```
`stage` required: `GRADE_11` | `GRADE_12` | `MATRIC_GRADUATE`. `subjects` requires at least one unique canonical supported subject; mark is integer 0–100 inclusive. `interests`, `province`, `studyModes` are optional and may be empty. No name, email, phone, national ID, household income or account field is permitted. Missing results remain missing, never zero.

### MatchResult
```json
{
  "programmeId": "UJ-2027-BSC-IT",
  "status": "UNKNOWN",
  "reasons": ["The applicable APS calculation rule is not verified."],
  "sources": [{"sourceId": "UJ-2027-PROSPECTUS", "sourceName": "Official source title", "sourceUrl": "https://example.org/official-source", "verifiedAt": "2026-10-16T12:00:00Z", "applicableCycle": "2027"}],
  "limitations": ["This is screening information, not an admissions decision."]
}
```
All properties are required; arrays may be empty only where the schema says so. `reasons` must be actionable and traceable. Do not return a numeric weighted match score.

### ApplicationTrackerEntry
```json
{
  "id": "local-opaque-id",
  "targetType": "PROGRAMME",
  "targetId": "UJ-2027-BSC-IT",
  "status": "DRAFT",
  "deadline": null,
  "requiredDocuments": [],
  "notes": null,
  "createdAt": "2026-10-16T12:00:00Z",
  "updatedAt": "2026-10-16T12:00:00Z",
  "statusIsLearnerReported": true
}
```
This is ephemeral page-memory data only. `id` is a random, opaque page-local identifier, not an API/database ID. `deadline` is ISO date or null; `notes` is string or null, maximum 2,000 Unicode characters. Required document items have `name` (1–120 characters) and `status` (`NOT_STARTED`, `IN_PROGRESS`, `READY`, `NOT_REQUIRED`). Entry status follows `ApplicationStatus`. `statusIsLearnerReported` must always be true in the MVP UI.

## 10. Validation limits

- JSON request/response payloads must be valid UTF-8 JSON.
- IDs: 1–100 characters, allowed pattern above.
- Human-facing title/name fields: 1–300 characters after trim; descriptions/notes must have documented limits at implementation and must never be trusted as HTML.
- Marks: integer only, 0–100 inclusive; decimals are rejected, not rounded.
- Duplicate canonical subject IDs are rejected even if entered through different aliases.
- Missing/unsupported rule facts must not be coerced to zero or treated as passing.
- Unknown fields in learner input are rejected; catalogue clients may ignore additive unknown response fields for forward compatibility but must reject missing required fields and invalid enums.
