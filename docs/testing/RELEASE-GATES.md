# Release Gates

## Pull request

- Unit/domain and contract tests pass.
- Frontend production build succeeds.
- Browser E2E/privacy/accessibility workflow passes on the exact PR head.
- No real learner data, secrets or unapproved service integration is introduced.
- Draft catalogue never produces definitive positive eligibility.
- Documentation and traceability reflect implementation.

## Hackathon demo

- Local start/reset/reload flow is repeatable.
- Synthetic data only.
- Catalogue limitations are clearly disclosed and official sources linked.
- No application submission, admission/funding guarantee, hosted backend or production readiness is claimed.
- Confirm current Sonke submission rules and upload details directly in the portal.

## Hosted deployment / production

Blocked and not authorized by this phase. Requires approved runtime architecture, service-by-service cost review against the R100/month cap, privacy/legal review, security controls, abuse/rate-limit configuration, curated published catalogue, secret/identity setup, infrastructure validation, deployment approval, smoke tests, monitoring and rollback plan.
